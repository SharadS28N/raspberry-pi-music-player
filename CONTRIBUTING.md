# Contributing to pi-aamps

We welcome contributions to **pi-aamps**!

## Development Guidelines
1. Ensure all code adheres to Python 3.10+ PEP8 standards.
2. Run automated unit tests before submitting pull requests:
   ```bash
   python -m pytest
   ```
3. Keep frontend responsive and glassmorphic using Tailwind CSS and Alpine.js.

Thank you for making pi-aamps better!
